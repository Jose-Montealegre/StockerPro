# 🚀 Stocker Pro

Sistema web para la gestión de inventarios, clientes y ventas de pequeños negocios.

## 📋 Descripción

Stocker Pro es una aplicación web desarrollada como proyecto de práctica profesional de Ingeniería de Software. Su objetivo es facilitar la administración de inventarios, clientes y ventas mediante una plataforma sencilla, intuitiva y escalable.

## 🛠 Tecnologías

- Python
- FastAPI
- React
- Vite
- PostgreSQL
- SQLAlchemy
- Git
- GitHub
